# Playwright action-fragment import (0.2.1)

The workshop accepts a deliberately narrow subset of recorded JavaScript actions.
It never evaluates source and does not persist recordings. It returns an unsigned
draft for explicit review in the editor. No browser replay is implemented yet.

Record with fictitious credentials only. Consult the official
[Playwright generator documentation](https://playwright.dev/docs/codegen).
Copy action lines out of the generated test; full test wrappers are rejected.

Supported syntax (one action per line, single/double quoted string literals):

```js
await page.goto('https://example.com/password');
await page.locator('#current-password').fill('fictional-old');
await page.locator('#new-password').fill('fictional-new');
await page.locator('#confirm-password').fill('fictional-new');
await page.locator('#submit').click();
```

Associate each fill selector with `fill-current-password`, `fill-new-password`,
or `fill-confirm-password`. All fill values are discarded, never inferred.
Bindings are operator-supplied: check them before signing. Username fields are
not supported yet. URLs must use the selected exact HTTPS origin and cannot
contain credentials, queries or fragments. URL paths and selectors are retained;
review them for private information. This is not a general secret detector.

Role/text locators generated by Codegen, assertions, imports, test wrappers,
expressions, template literals and arbitrary JavaScript are rejected. Adapt the
recording to supported CSS locator actions manually. Nothing is silently skipped
except blank lines and full-line comments. Errors never echo recorded source.

The resulting draft ends with a manual checkpoint. Add independent success
verification before future execution; importing or signing is not a successful
replay. The simulated runner does not execute these actions.

API: `POST /api/templates/convert-codegen` with `source`, `allowedOrigin`, and
`bindings`. Returns `steps`, `removedValues`, `reviewRequired`, `schemaVersion`.
No import event includes source or fill values.

Next: structured role/label locators, a dedicated test website, actual browser
replay with network restrictions, and an independently verified success result.
